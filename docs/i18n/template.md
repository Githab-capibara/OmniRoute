# I18n — authoring template

`docs/i18n/<locale>/` mirrors the English `docs/` tree, generated by
`npm run i18n:run` (not hand-edited). Translate a new doc by adding it to the
English source and re-running the adoption:

```sh
npm run i18n:run -- --adopt --targets-only
npm run i18n:check
```

The machine index [llm.txt](../../llm.txt) is mirrored per locale
(`docs/i18n/<locale>/llm.txt`) and kept byte-exact with the root file.
