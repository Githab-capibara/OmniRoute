# Plean Clúdach Tástála

Nuashonrú deireanach: 2026-06-28

> Stádas a thomhais ar 2026-05-13: línte 82.58%, ráitis 82.58%, feidhmeanna 84.23%, brainse 75.22%. Tá na Céimeanna 1-5 críochnaithe. Is é fócas reatha Céim 6 (≥85%) agus Céim 7 (≥90%).

## Bunchairt

Tá roinnt uimhreacha clúdaigh ann ag brath ar an gcaoi a gcoinnítear an tuairisc. Le haghaidh pleanála, níl ach ceann amháin inúsáide.

| Méadracht       | Scóip                                                                       | Ráitis / Línte | Brainse | Feidhmeanna | Nótaí                                                                        |
| --------------- | --------------------------------------------------------------------------- | -------------: | ------: | ----------: | ---------------------------------------------------------------------------- |
| Oidhreacht      | Seanchlúdach `npm run test:coverage`                                        |         79.42% |  75.15% |      67.94% | Méadaithe: áirítear comhaid tástála agus dhéantar neamhdearmad ar `open-sse` |
| Diagnóiseach    | Foinse amháin, ag fáil réidh le tástálacha agus ag fáil réidh le `open-sse` |         68.16% |  63.55% |      64.06% | Ní úsáideach ach chun `src/**` a fhreagairt                                  |
| Bunchairt molta | Foinse amháin, ag fáil réidh le tástálacha agus ag áireamh `open-sse`       |         82.58% |  75.22% |      84.23% | Is é seo an bunchairt fud na tionsclaíochta le feabhsú                       |

Is é an bunchairt molta an uimhir le bharrfheabhsú.

## Rialacha

- Is iad comhaid foinse atá i gceist le spriocanna clúdaigh, ní `tests/**`.
- Tá `open-sse/**` mar chuid den táirge agus ní mór é a choinneáil sa raon.
- Ní cheart don chód nua an clúdach a laghdú i gceantair a théann sé i bhfeidhm orthu.
- Is fearr iompar agus thoradh brainse a thástáil ná sonraí cur i bhfeidhm.
- Is fearr bunachair shonraí SQLite sealadacha agus giuirléidí beaga ná mionghámaí leathan do `src/lib/db/**`.

## Tacar ordaithe reatha

- `npm run test:coverage`
  - Príomhghátar clúdaigh foinse don tsraith tástála aonaid
  - Gineann sé `text-summary`, `html`, `json-summary`, agus `lcov`
- `npm run coverage:report`
  - Tuairisc mhionsonraithe comhad ar chomhad ón rith is déanaí
- `npm run test:coverage:legacy`
  - Cur síos stairiúil amháin

## Polasaí Ratchet

Ná nuashonraigh na leibhéalacha `npm run test:coverage` ach tar éis don tionscadal sárú an chéad mhílechléire le bufer fholláin.

**Geata reatha:** Éilíonn `npm run test:coverage` **60 ráiteas / 60 líne / 60 feidhm / 60 brainse** (athbhunsaíodh an tomhas i Quality-Gates Fase 6A.1 — bhí an bonnlíne 82.58% níos luaithe bláthaithe mar go raibh sé ag comhaireamh comhaid tástála agus d'fhág sé `open-sse` ar lár). Cosnaíonn an t-ordú `test:coverage:legacy` an seanmheaschruacháin 50/50/50 le haghaidh comparáide stairiúil.

Chun seiceáilí ad hoc ar an leibhéal a dhéanamh i gcoinne an tuairisc is déanaí úsáid:

```bash
node scripts/check/test-report-summary.mjs --threshold 75
```

Seqú ratchet molta (ord: `statements-lines / branches / functions`):

1. 55/60/55
2. 60/62/58
3. 65/64/62
4. 70/66/66
5. 75/70/72 <-- geata reatha (75/70/75)
6. 80/75/78
7. 85/80/84
8. 90/85/88

Is é sprioc ratchet atá romhainn `80/75/78` nuair a sheasfaidh clúdach na mbraistí os cionn 78% ar feadh dhá rith as a chéile.

## Bhearna aitheanta

Mheasann an t-ordú clúdach reatha an tsraith taispeáint Node príomhúil agus cuireann sé san áireamh an foinse a shroichfidh sé sin, lena n-áirítear `open-sse`. Ní thuilleann sé Vitest clúdach a chomhtháthú ina tuairisc aontaithe amháin fós. Is fiú an tionscnamh comhtháthaithe sin a dhéanamh níos déanaí, ach ní bac é chun tús a chur leis an ardú ó 60% go 80%.
