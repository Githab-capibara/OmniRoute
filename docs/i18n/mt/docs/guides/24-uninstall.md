## Tneħħija Rapida (v3.6.2+)

OmniRoute tipprovdi żewġ skripts interni għat-tneħħija nadif:

### Ħu Ġejjiena Data Tiegħek

```bash
npm run uninstall
```

Dan ineħħi l-applikazzjoni OmniRoute iżda **jippreserva** d-database, il-konfigurazzjonijiet, iċ-ċav API, u t-taħdid tal-fornituri f'`~/.omniroute/`. Għoġbok dan jekk tixtieq terġa' tinstalla aktar tard u trid iżżomm l-issettjar tiegħek.

### Tneħħija Sħiħa

```bash
npm run uninstall:full
```

## Tneħħija Manwali

### Installazzjoni Globali NPM

```bash
# Neħħi l-pakkett globali
npm uninstall -g omniroute

# (Fakultattiv) Neħħi d-direttorija tad-dejta
rm -rf ~/.omniroute
```

### Installazzjoni Globali pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Waqaf u neħħi l-kontenitur
docker stop omniroute
docker rm omniroute

# Neħħi l-volum (jelimina l- dejta kollha)
docker volume rm omniroute-data

# (Fakultattiv) Neħħi l-istampa
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Waqaf u neħħi l-kontenituri
docker compose down

# Neħħi ukoll il-volumi (jelimina l-dejta kollha)
docker compose down -v
```

### App tal-Desktop Electron

**Windows:**

- Agħlaq `Settings → Apps → OmniRoute → Uninstall`
- Jew ħdimma l-uninstaller NSIS mid-direttorija tal-installazzjoni

**macOS:**

- Seħħi `OmniRoute.app` minn `/Applications` lejn il-ħmieġ
- Neħħi d-dejta: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Neħħi l-fajl AppImage
- Neħħi d-dejta: `rm -rf ~/.omniroute`

### Installazzjoni minn sors (git clone)

```bash
# Neħħi d-direttorija maqsuma mal-oħrajn
rm -rf /path/to/omniroute

# (Fakultattiv) Neħħi d-direttorija tad-dejta
rm -rf ~/.omniroute
```

## Direttoriji tal-Dejta

OmniRoute jiffranka d-dejta fil-lokazzjonijiet li ġejjin b'mod assolut:

| Pjattaforma      | Triq Assoluta                 | Override                               |
| ---------------- | ----------------------------- | -------------------------------------- |
| Linux            | `~/.omniroute/`               | Varjanti tal-ambjent `DATA_DIR`        |
| macOS            | `~/.omniroute/`               | Varjanti tal-ambjent `DATA_DIR`        |
| Windows          | `%APPDATA%/omniroute/`        | Varjanti tal-ambjent `DATA_DIR`        |
| Docker           | `/app/data/` (volum maħruġ)   | Varjanti tal-ambjent `DATA_DIR`        |
| Konformi mal-XDG | `$XDG_CONFIG_HOME/omniroute/` | Varjanti tal-ambjent `XDG_CONFIG_HOME` |

### Fajls fid-direttorija tal-dejta

| Fajl/Direttorija     | Deskrizzjoni                                                 |
| -------------------- | ------------------------------------------------------------ |
| `storage.sqlite`     | Database ewlieni (fornituri, kombo, impostazzjonijeti, kijs) |
| `storage.sqlite-wal` | Log tal-kitba ta' qabel SQLite (temporary)                   |
| `storage.sqlite-shm` | Memorja maqsuma SQLite (temporary)                           |
| `call_logs/`         | Arċivji tal-pagament tal-ħatriet                             |
| `backups/`           | Riservi awtomatiċi tal-database                              |
| `log.txt`            | Log tal-ħatriet leġiżlu (fakultattiv)                        |

## Tverifika t-Tneħħija Kompleta

Wara t-tneħħija, tivverifika li ma jkunx hemm fajls li fadal:

```bash
# Ġejja tivverifika l-pakkett npm globali
npm list -g omniroute 2>/dev/null

# Ġejja tivverifika d-direttorija tal-dejta
ls -la ~/.omniroute/ 2>/dev/null

# Ġejja tivverifika l-proċessi li qed jaħdmu
pgrep -f omniroute
```

Jekk xi proċess għadu qed jaħdem, waqfu:

```bash
pkill -f omniroute
```
